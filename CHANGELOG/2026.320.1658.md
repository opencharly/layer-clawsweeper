# 2026.320.1658 — fix(clawsweeper-review): libicu74 -> libicu78, because ICU is not version-stable on Ubuntu

## Summary

The second half of opencharly/layer-clawsweeper#11, which **landed only its first commit**. The Arch
package set is on `main`; this ICU fix is not. Measured on `main`:

```
$ git show origin/main:candy/clawsweeper-review/charly.yml | grep -n libicu
35:                    - libicu74
```

ICU is **not version-stable across Ubuntu releases**, and this is a measured fork, not a typo:

```
ubuntu:24.04   OK libicu74    MISS libicu78
ubuntu:26.04   MISS libicu74  OK   libicu78
```

so a candy pinned to `libicu74` cannot build on the base the org now defaults to
(opencharly/opencharly#1068). The measured failure on that base:

```
E: Unable to locate package libicu74
```

The other eight packages are unchanged and verified present on 26.04: `git`, `curl`,
`ca-certificates`, `xz-utils`, `jq`, `python3`, `bubblewrap`, `libssl3t64`.

**Why a rename and not a versioned `distro:` section:** the org's default Ubuntu is 26.04 and this
candy's only consumer (`distro-ubuntu`'s `box/clawsweeper-review`) builds there. A version-specific
section would keep 24.04 building too, but **no candy in the corpus uses one**. That is not a recollection — it is this command and its output,
run over every `charly.yml` in the org's module cache (406 files):

```
$ M=$GOMODCACHE/github.com/opencharly
$ grep -rhoE '^\s+(ubuntu|debian|fedora|arch|alpine)(-[0-9]+\.[0-9]+|:[0-9]+\.[0-9]+):' "$M" --include=charly.yml | sort -u
$ echo "VERSIONED_DISTRO_KEYS=$(… | wc -l)"
VERSIONED_DISTRO_KEYS=0
$ find "$M" -name charly.yml | wc -l
406
```

So adopting that schema shape is a separate, deliberate decision that a candy fix should not make on its
own.

**RCA for the skip:** `check-codex-runtime` is `context: [runtime]` — it inspects a RUNNING deployment —
and `charly check box` evaluates build-context checks against the image, so a runtime-scoped step is
correctly out of scope. It executes in the pod bed that deploys this image
(`distro-cachyos`'s `check-clawsweeper-review-pod`, already merged).

The proof built a temporary local candy copy (the box's `@github` ref swapped for the bare local name);
both were reverted afterwards and the `distro-ubuntu` worktree is back to `git status` clean.
